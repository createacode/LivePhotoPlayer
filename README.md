# 实况照片播放器 v4.8.0 - Copyright © XAF 2026.11

## 一眼看懂

手机拍的「实况照片」，在电脑上只是一张普通的 JPG：会动的几秒视频藏在这张照片的尾部，
资源管理器看不见、播放器也打不开。**实况照片播放器**把它们还原成「一张会动的照片」，
并且像看相册一样顺手地翻页、缩放、导出。

- 目标用户：用 OPPO / 一加 / realme / 小米 / 三星 / iPhone 拍实况照片，希望在 Windows 上浏览和导出的人。
- 解决的核心问题：Windows 上没有能直接「点一下就让实况照片动起来」的轻量工具。
- 不适用：专业视频剪辑、照片修图、云相册同步。

## 为什么值得用

- **一张照片，两种看法**：打开就是高清照片，点中间就播放那几秒实况，播完自动回到照片，不闪黑屏。
- **不用等**：相邻照片在后台提前解码，翻页几乎瞬时；48MP 大图也能顺滑缩放拖动。
- **原样导出**：照片导出为 JPG（HEIC 自动转码），实况视频导出为标准 MP4，方便发微信、传网盘。
- **完全本地**：不联网、不上传、不写注册表；除检查更新外不发起任何网络请求。
- **单文件配置**：所有设置存放在程序目录的 `config/config.json`，拷走就能带走习惯。

## 主要功能

| 功能 | 说明 |
| --- | --- |
| 实况照片识别 | 支持 `Item:Length` / `MicroVideoOffset` 两类元数据，识别失败时回退搜索文件尾部的 `ftyp` 标记 |
| 实况播放 | 直接从照片尾部播放内嵌视频，不生成临时文件；播放结束自动回到照片 |
| 照片浏览 | 滚轮以光标为中心缩放、放大后拖动平移、双击在「适应窗口 / 100%」之间切换 |
| 区域点击 | 适应窗口时，点击左 1/3 上一张、中间播放、右 1/3 下一张 |
| 外部视频 | 直接播放 MP4 / MOV / AVI / MKV，带封面，点击封面开始播放 |
| 文件列表 | 自动列出同目录媒体，支持方向键与单击切换，列表跟随当前照片 |
| 导出 | 照片导出到 `照片/`，视频导出到 `视频/`，文件名带时间与随机后缀且不会覆盖已有文件 |
| 自动播放 | 可切换「切换照片即播放实况」或「点击才播放」 |
| 记忆与托盘 | 记住上次目录、窗口位置与大小、播放速度、静音、自动播放；关闭窗口最小化到托盘 |
| 收藏 | 一键星标；收藏时自动把副本复制到 `收藏/` 文件夹；收藏夹分「收藏时间线」「拍摄时间线」两个标签 |
| 时间线 | 主界面可切换「默认排序 / 拍摄时间线」，按天分组，时间与拍摄地点醒目展示 |
| 全库搜索 | 按文件名、地点、日期、相机型号搜索，输入即筛，无需等待 |
| 结构化索引 | 后台静默建立照片目录（拍摄时间、GPS、相机型号），可断续恢复、有变动自动更新 |
| 检查更新 | 从 Gitee 发行版检查新版，校验 SHA-256 后才交给用户确认安装 |

## 三分钟上手

1. 双击 `LivePhotoPlayer.exe` 启动。
2. 把一张实况照片拖进窗口（或点「打开文件」）。
3. 点照片中间区域 → 实况开始播放；播完自动回到照片。
4. 左右方向键翻页，滚轮缩放，双击还原。

常用快捷键：

| 操作 | 快捷键 |
| --- | --- |
| 上一张 / 下一张 | `←` `↑` / `→` `↓` |
| 播放 / 暂停 | `Enter` 或空格 |
| 停止播放 | `Esc` |
| 适应窗口 / 实际大小 | `Ctrl+0` / `Ctrl+1` |
| 放大 / 缩小 | `Ctrl++` / `Ctrl+-` |
| 打开文件 / 文件列表 | `Ctrl+O` / `Ctrl+L` |
| 退出 | `Ctrl+Q` |

## 画质

- 照片统一转换到 **sRGB** 再显示：手机拍的 Display P3 直接按 sRGB 显示会掉约 27% 彩度。
- 缩小显示时做**标准 USM 锐化**（Pillow C 实现，半径 0.8、强度 45%、阈值 2），
  1:1 与放大不锐化，保持原生像素。
- 工具栏「更多 → 画质」可选 **原始 / 标准 / 增强**，实测锐度分别 +0% / +70% / +190%。

## 时间线、搜索与收藏

- **时间线模式**：点工具栏「时间线」（或按 `Ctrl+T`）进入**全屏独立界面**——左侧列表会隐藏，
  一条竖轴贯穿，按天分区，每行「时间 → 大图 → 地点」。
  - 顶部可按「上一天 / 下一天 / 日期下拉 / 选日期」跳转；缩放滑块可把照片放大到 2.2 倍；
  - **长按竖轴上的点再上下拖动**，可按日期跨度快速滚动；
  - 右键只有四项：预览、播放实况、收藏、在文件夹中显示；
  - 命令行也可直接进入：`LivePhotoPlayer.exe 目录 --timeline`。
- **预览浮窗**：双击任意一张打开无边框悬浮窗，可上下翻页、空格播放实况、`Esc` 或 ✕ 关闭，
  「返回时间线」一键切回。

- **拍摄时间线**：列表按拍摄时间倒序，按天分组（`2026-09-27 周日`），每行显示**拍摄时刻**与**拍摄地点**。
  时间取自照片 EXIF；视频没有 EXIF 时取文件名里的时间戳（如 `VID20260809154030`），比文件修改时间可靠。
- **地点**：照片读 EXIF GPS；视频没有 EXIF，改读 MP4 的 `©xyz`（ISO-6709）坐标。默认用**内置的 2889 个区县坐标表**在本地换算成
  `河北省 承德市 丰宁满族自治县`，全程不联网；设置里可切换到**在线 API**
  （天地图，key 由你自己填；或免 key 的 OpenStreetMap）获得更精确的结果。
  离线是按区县中心点就近匹配，边境附近可能偏差到邻县，需要精确时请用在线模式。
- **搜索**：输入文件名、日期（`2026-09`）、相机型号即可全库检索，结果本身也按时间线排列。
- **收藏**：按 `Ctrl+D` 或点工具栏星标，照片会被复制一份到程序目录下的 `收藏/`，
  文件名带拍摄时间，便于脱离本软件也能找到。「收藏夹」里可以按**收藏时间**或**拍摄时间**两种时间线查看。

> 结构化索引在后台以最低优先级慢慢进行，每处理一个文件主动让出 CPU，
> 不弹窗、不抢焦点、不影响翻页；关掉软件下次会从断点续扫。

## 系统要求

- Windows 10 1809 及以上 / Windows 11，64 位。
- 无需安装 Python，也无需安装 VLC 或任何解码器。
- 支持 100% ~ 200% 的高 DPI 缩放。
- 实况照片格式识别以 OPPO 系（含一加、realme）为主，同时兼容 Google 风格运动照片；
  视频播放依赖 Qt 自带的 FFmpeg 组件，可解码 H.264 / HEVC / AAC 等常见编码。

## 数据与隐私

- 程序只在本地读写你打开的文件与自身目录下的 `config/`、`logs/`、`照片/`、`视频/`、`收藏/`。
- 照片索引（拍摄时间、GPS 坐标、相机型号）保存在本机 `%LOCALAPPDATA%\LivePhotoPlayer\cache\catalog.db`，不会上传。
- 日志仅记录启动、退出、加载与错误信息，不记录照片内容，不含任何个人身份信息。
- 除「检查更新」会访问 Gitee 发行版接口外，程序不进行任何网络通信。
- 地点解析默认**完全离线**（内置区县表）；只有你主动切到在线模式并点了保存，
  才会把照片坐标发给天地图或 OpenStreetMap 反查地名，结果只缓存在本机数据库。

## 已知限制

- 仅支持 Windows 桌面端，不支持 macOS / Linux。
- 实况照片的「动态」部分长度由拍摄设备决定，通常为 1.5 ~ 3 秒。
- 若照片本身不含内嵌视频（例如关闭了实况拍照），程序会按普通照片展示并明确提示。
- 未签名的可执行文件首次运行可能触发 SmartScreen 提示，选择「更多信息 → 仍要运行」即可。
